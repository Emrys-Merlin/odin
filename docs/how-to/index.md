# How-to guides

Steps for one task you already know you want to do. They assume ODIN is running; background is in
[Explanation](../explanation/index.md), exact options in [Reference](../reference/index.md).

- **Operate** — upgrade, roll back, back up, change groups or config, troubleshoot.
- **In the chat** — for flatmates: cancel a dinner, edit a text, move dinner, pause the nudge.
- **Develop** — run ODIN locally, add a chat command, release, write docs.
